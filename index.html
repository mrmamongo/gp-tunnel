О приложении

GP Relay подключается к корпоративному VPN GlobalProtect через Docker и создаёт локальный SOCKS5-прокси. Через VPN идут только приложения, в которых настроен этот прокси.

Как подключиться

  1. Откройте Docker Desktop и дождитесь его запуска.
  2. Введите логин, пароль и порт SOCKS. По умолчанию — 1080.
  3. Нажмите «Подключить». Если сервер попросит, введите одноразовый код или выберите шлюз, затем нажмите «Продолжить».
  4. В нужном приложении укажите SOCKS5-прокси:socks5h://127.0.0.1:1080Включите DNS через прокси, если такая настройка есть.

«Запомнить пароль» сохраняет его после успешного входа с защитой Windows.
