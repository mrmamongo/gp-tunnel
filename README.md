# GP Relay

Компактное Windows-приложение в трее для GlobalProtect через OpenConnect в Docker.

## Использование

1. Запустите Docker Desktop, затем GP Relay. Приложение появляется только в трее.
2. Нажмите значок левой кнопкой мыши. Введите логин, пароль и локальный порт SOCKS (по умолчанию `1080`). Портал `gp.domru.ru` задан по умолчанию; ранее сохранённый адрес сохраняется в настройках и не занимает места в форме.
3. Нажмите «Подключить». Одноразовый код, выбор шлюза и другие запросы появятся в той же панели, когда их запросит сервер.
4. В приложениях используйте `socks5h://127.0.0.1:<порт>`, чтобы DNS-запросы также выполнялись через прокси.

Кнопка «−» в шапке, клик снаружи, Escape, повторный клик по значку и Alt+F4 скрывают панель, сохраняя VPN. Правый клик по значку открывает меню «Открыть», «Отключить», «Выйти». Явный выход сначала отключает VPN. Если остановку не удалось подтвердить, приложение остаётся в трее и предлагает повторить отключение после восстановления Docker.

Цвет значка показывает состояние: серый — отключено, синий — операция выполняется, зелёный — подключено, жёлтый — нужен ввод, красный — ошибка. Ожидающий MFA не открывает окно поверх других программ. Повторный запуск открывает уже работающий экземпляр.

Адрес, логин и порт сохраняются локально. Галочка «Запомнить пароль» сохраняет пароль через Windows DPAPI после успешного входа. Пароль привязан к порталу и не загружается для другого адреса. Снятие галочки удаляет сохранённый пароль. MFA не сохраняется. Запись старой версии без портала привязывается к текущему адресу после следующего успешного входа.

При обновлении сначала выберите «Выйти» в меню трея и дождитесь исчезновения значка, затем запустите новый файл. Запуск новой сборки при работающей старой только открывает старый экземпляр. Версия отображается в подсказке значка.

## Устройство

- Tauri 2 + Rust управляют треем, состоянием VPN, Docker и интерактивной авторизацией.
- TypeScript отображает панель шириной 340 логических пикселей с системной темой и доступной клавиатурной навигацией.
- Контейнер `gp-relay`: Alpine, OpenConnect, Dante и socat. SSH не используется.
- Образ `ghcr.io/mrmamongo/gp-relay:latest` загружается при необходимости. Если pull не удался, приложение собирает образ из встроенного контекста (для загрузки Alpine и пакетов нужна сеть).
- Dante слушает `1080` внутри контейнера. Публикация на Windows — только `127.0.0.1:<выбранный порт>`.
- Подходящий остановленный контейнер запускается повторно. При изменении порта контейнер пересоздаётся, если в нём нет активного OpenConnect. Занятый порт не заменяется автоматически.
- Скрытие панели не влияет на авторизацию: Rust отвечает логином и паролем по одному разу на этапе портала и повторно после выбора шлюза. Повторный запрос на том же этапе требует ручного исправления; MFA всегда вводится отдельно.
- Отключение использует Ctrl-C, затем SIGINT, при необходимости удаление контейнера. Завершение подтверждается проверкой процесса внутри контейнера.

Системные маршруты и прокси Windows не изменяются. Поддерживается один портал и одна VPN-сессия. SAML, автоподключение и автозапуск Windows не реализованы. При оставшейся сессии от старой версии сначала завершите её вручную; приложение не присваивает и не пересоздаёт контейнер с работающим OpenConnect.

## Разработка

Нужны Node.js, pnpm, Rust и Windows build tools, WebView2. Для интеграционных проверок нужен работающий Docker Desktop.

```powershell
pnpm install --frozen-lockfile
pnpm build
cargo check --manifest-path src-tauri/Cargo.toml
cargo test --manifest-path src-tauri/Cargo.toml
pnpm exec playwright install chromium
pnpm test:ui
pnpm tauri dev
```

Vite запускается на фиксированном порту `1420`. В dev-режиме приложение также стартует скрытым в трее.

```powershell
pnpm tauri build
.\scripts\build-portable.ps1 -Zip
```

Windows CI проверяет frontend и Rust-тесты, собирает NSIS и portable-комплект. Docker-образ публикуется отдельным workflow при изменении `docker/`.

## Проверка вручную

- Скрытый старт без вспышки окна и кнопки в панели задач; один значок при повторном запуске.
- Открытие/скрытие по значку, Escape, клик снаружи, Alt+F4, контекстное меню, выход во время подключения.
- Светлая и тёмная темы, масштаб 100/150/200%, разные мониторы и положение панели задач, длинный адрес/ошибка, MFA и шлюзы без обрезания.
- Docker отсутствует/остановлен; получение образа; существующий остановленный контейнер; занятый/изменённый порт; отмена подготовки.
- Реальный вход с участием пользователя: неверный пароль, повторный запрос, MFA, выбор шлюза, скрытая панель, DPAPI после успешного входа.
- После отключения проверить отсутствие OpenConnect; после выхода не должно оставаться активного VPN.
